## 自动测试与启动检查

自动测试使用模拟翻译接口及模拟语音生成，不代表真实大模型翻译质量。Windows 凭据测试只使用独立的 `.invalid` 测试地址，并在结束时删除。

源码和便携程序可使用 `--smoke-test <报告文件路径>` 检查托盘、原生键盘线程和 Qt 启动；不发送论文文本或调用翻译服务。

## 真实服务验收（用户配置 Key 后）

分别测试 DeepSeek 和 MiMo，不共享测试结论。建议样本：`attention`、`kernel`、`throughput`、`memory bandwidth`、`The scheduler minimizes latency while preserving throughput.`，再加入你熟悉的论文段落。

记录服务商、模型、时间、原文、结果、术语准确性、首次文字出现时间和总时间。无上下文的单词应显示可能含义；公式、数字及引用应保留。对速度目标做多次测量，缓存命中与首次网络请求分别记录。

语音验证英美音色、语速、停止、新任务替换、断网提示、系统语音备用与清理缓存。首词句翻译 2 秒／单词音频 2.5 秒为优化目标，取决于地区网络和服务商，尚非通过实测的保证。
