# 后续规划

第一版只实现取词、翻译、朗读及设置。以下内容尚未实现，不展示占位操作按钮。

## 生词本与论文关联

- 用户手工创建或选择当前论文，将单词、释义、原句关联到论文。
- 本地保存用户自定义词条；支持编辑、删除、按论文筛选及导出。
- 区分首次记录与重复遇见，避免同一论文出现大量重复词条。
- 后续再评估 Zotero 插件，用稳定的论文标识连接记录，而不是依赖窗口标题猜测。

## 标记与复习

- 卡片内加入记录生词入口；论文内高亮需要阅读器专用接口，不能承诺一个全局工具直接修改所有软件的文档。
- 学习状态、复习与统计在真实使用需求明确后再建设。

## 其他候选

- 扫描论文 OCR 框选取词。
- Ctrl+D D 可选触发方式，明确提示原快捷键冲突。
- 官方语音 API、离线自然语音与 macOS 适配。
