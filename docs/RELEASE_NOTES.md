# v0.1.3 — MiMo 地址与密钥配置修复

设置区分 MiMo 按量付费与 Token Plan 中国、新加坡、欧洲接口，使用对应的官方地址和认证头。发送前提示 tp-/ttp- 与按量付费地址混用、sk- 与 Token Plan 地址混用，以及误粘贴 MiMokey: 标签；不会自动改用其他计费服务或区域。

修复密钥输入框在地址未变化时覆盖新输入，以及凭据读取失败后返回原地址时未重新加载的问题。兼容既有 MiMo 设置，保留用户配置的地址与模型。

82 项自动测试通过，覆盖率 94%。真实账号未测试；Token Plan 接口兼容不代表套餐允许文献翻译用途，普通个人套餐的编程用途限制见 [官方说明](https://mimo.mi.com/docs/tokenplan/subscription)。文献翻译请使用适用的按量付费 API。程序继续覆盖固定位置，清除旧音频缓存，保留设置和凭据。

## v0.1.2 — 音频输出恢复与旧事件隔离

修复连续朗读时旧播放器迟到事件可能清除新语音任务的问题。每次播放重新建立输出连接，媒体回调同时检查任务编号与播放器身份。增加「计时但无声？恢复声音」，在本地重新连接并回退 1 秒继续；设备变化会停播并提示，卡片显示当前输出设备，设置标题显示版本。

构建固定覆盖 `dist/HelloXiaoyi`。新版语音缓存按版本清理，保留用户设置和密钥。开发期交付仅保留当前程序与当前便携包。

用户的 `MDP instantiation. Let Ht denote...` 样本缓存与重新合成结果一致，Let 后有波形且 Windows 回环有输出。旧事件误清除任务已通过模拟复现并修复；Bose 耳机实际听感的间歇性中断尚未复现，不宣称此版本已排除所有原因。详细数据见 `TESTING.md`。

## v0.1.1 — 朗读稳定性修复

- 同一段原文在生成／播放期间，重复点击或触发朗读不会中断并从头播放。
- 卡片因失焦自动收起时，英文朗读继续；可通过停止按钮、Esc 或托盘停止。
- 显示朗读进度、正常完成和意外中断；完成或失败后可重新朗读。
- 使用反馈中的双句英文样例验证，实际 Qt 播放器完整播放到 11.40 秒；覆盖重复请求和被动收起回归。

请从托盘退出旧版再启动新版，原有设置和密钥继续使用。用户原场景是否完全消除中断仍需复测。

## 首版能力

- Windows 托盘常驻，按住 Ctrl 在 600ms 内连按两次 C 取词；普通复制保持正常。
- 英译中流式卡片、单词常用义和学术义、点击自然英文朗读。
- DeepSeek / MiMo / 自定义 HTTPS 兼容接口，密钥存 Windows 凭据管理器。
- 英美在线音色、语速、系统英文语音备用、设置试听及可选开机启动。
- 便携 ZIP 自带 Python 和 Qt；请解压后运行 HelloXiaoyi.exe，保留同目录文件。

在设置中填写自己的 API Key，测试连接后保存。无需密钥即可试听在线语音。

这是首版测试包：真实模型翻译质量、Chrome/Edge/PDF/Zotero 的完整人工兼容性、多显示器及干净 Windows 环境仍需按 docs/TESTING.md 验收。生词本、论文关联、OCR 尚未实现。
